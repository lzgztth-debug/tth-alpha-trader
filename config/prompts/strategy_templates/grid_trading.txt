# 网格交易策略 (Grid Trading)

## 策略说明
网格交易策略在设定的价格区间内，按照固定的价格间隔（网格）放置买卖订单。
价格每下跌一个网格间距就买入一份，每上涨一个网格间距就卖出一份。
该策略通过不断低买高卖来积累利润，适合震荡行情。

## 决策规则

### 网格参数
- 上界价格: {{grid_upper}}（网格区间最高价）
- 下界价格: {{grid_lower}}（网格区间最低价）
- 网格数量: {{grid_count}}（网格等分数）
- 网格间距: {{grid_step}}（每格价格差 = (上界-下界) / 网格数量）
- 每格投入金额: {{grid_amount}}（每格交易的资金量）
- 当前价格: {{current_price}}

### 买入规则
1. 当前价格 {{current_price}} 跌至某个网格买入线附近（价格 <= 买入线 * 1.001）
2. 当前持仓中该网格对应的仓位尚未建仓
3. 账户可用资金 {{available_cash}} >= {{grid_amount}}
4. 当前价格仍在网格区间内（{{grid_lower}} <= 价格 <= {{grid_upper}}）

### 卖出规则
1. 当前价格 {{current_price}} 涨至某个网格卖出线附近（价格 >= 卖出线 * 0.999）
2. 当前持仓中该网格对应的仓位已建仓
3. 卖出可产生正向利润（卖出价 > 买入价 * (1 + 手续费率)）

### 异常处理
1. 价格突破上界 {{grid_upper}}: 全部清仓，暂停网格交易
2. 价格跌破下界 {{grid_lower}}: 停止买入，持有等待反弹或止损
3. 价格单边快速波动: 暂停交易，等待价格稳定

## 参数说明
- {{grid_upper}}: 网格上界价格
- {{grid_lower}}: 网格下界价格
- {{grid_count}}: 网格数量（建议10-50）
- {{grid_step}}: 网格间距
- {{grid_amount}}: 每格投入金额
- {{symbol}}: 交易标的代码
- {{current_price}}: 当前价格
- {{available_cash}}: 可用现金
- {{stop_loss_pct}}: 整体止损百分比（默认10%）

## 风险提示
1. 网格交易在单边趋势中可能持续亏损：上涨时卖飞，下跌时不断加仓被套
2. 必须设置网格区间的整体止损线
3. 网格间距不宜过小，否则手续费会侵蚀利润
4. 网格区间应根据标的的历史波动率合理设定
5. 关注资金利用率，避免过多资金被锁定在单个标的上
6. 建议选择波动率适中、流动性好的标的进行网格交易

## 输出要求
请根据以上规则分析当前价格在网格中的位置，输出JSON格式的交易决策：
{
  "action": "buy|sell|hold",
  "symbol": "{{symbol}}",
  "quantity": 建议数量,
  "price": "建议价格（网格线价格）",
  "confidence": 0.0-1.0,
  "reasoning": "基于网格交易策略的分析理由，说明当前价格所在网格位置"
}
